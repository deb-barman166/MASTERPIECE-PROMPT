## 📖 Overview

The **Ultimate Prompt Engineering Library** is a complete, self-contained reference covering **80 distinct prompt engineering techniques** — everything from `Zero-Shot Prompting` to full `Agentic Workflow Prompting` — each documented as a standalone, production-ready guide.

This isn't a loose collection of tips. It's a structured handbook designed to take someone from **"I don't know what to type into an AI model"** to **"I can architect a multi-agent, tool-using, self-optimizing AI system"** — with every technique explained, justified, and demonstrated at three levels of difficulty.

Every one of the 80 files follows the **exact same 10-part structure**, so the library reads consistently whether you're on file `01` or file `80`:

1. **Title**
2. **Definition**
3. **Purpose**
4. **When to Use & Best Model/LLM**
5. **Prompt Formula**
6. **Prompt Structure**
7. **Best Practices**
8. **Common Mistakes**
9. **Examples** (Basic → Intermediate → Advanced)
10. **Reusable Prompt Template**

> 🔗 **Every technique name in the index below is a direct link** — click any row and it opens that exact `.txt` file. No searching through folders.

## 🧩 What's Inside Every File

Each `.txt` guide is a complete, standalone reference — no file assumes you've read another one first. A typical entry runs **250–400 lines** and includes:

- ✅ A **plain-language definition** and the problem the technique actually solves
- ✅ **Model-specific guidance** — which LLMs (GPT, Claude, Gemini, Grok, DeepSeek, Qwen, Mistral, Llama) handle the technique best, and why
- ✅ A **copy-paste prompt formula** and full structural breakdown
- ✅ **Best practices** grounded in how these techniques actually behave in production
- ✅ **Common mistakes** — the specific failure modes people hit, and how to avoid them
- ✅ **Three fully worked examples** (Basic → Intermediate → Advanced) so you can see the technique scale with real complexity
- ✅ A **reusable template** you can drop straight into your own prompts or codebase

## 🚀 How to Use This Library

**If you're new to prompt engineering:**
Start at [`01_Zero-Shot_Prompting.txt`](prompt_library_part1/01_Zero-Shot_Prompting.txt) and work through the Foundations cluster (01–10) in order. These techniques are the building blocks everything else in the library depends on.

**If you're building AI agents or multi-agent systems:**
Jump to the Agentic clusters — [`23_ReAct_Prompting`](prompt_library_part1/23_ReAct_Prompting.txt), [`27_Multi-Agent_Prompting`](prompt_library_part1/27_Multi-Agent_Prompting.txt), [`30_Tool-Use_Prompting`](prompt_library_part1/30_Tool-Use_Prompting.txt), [`31_Function_Calling_Prompting`](prompt_library_part1/31_Function_Calling_Prompting.txt), and the capstone, [`80_Agentic_Workflow_Prompting`](prompt_library_part2/80_Agentic_Workflow_Prompting.txt), which shows how every agentic pattern in the library integrates into one production architecture.

**If you're doing AI-assisted development:**
The Coding cluster (54–59) covers the full development loop — generation, debugging, review, refactoring, testing, and documentation — as six distinct, deliberately-scoped techniques rather than one blurry "coding prompt."

**If you're working on creative or media projects** (video editing, photo editing, AI-generated content):
The Creative cluster (46–53) covers Story, Screenplay, Image, and Video Prompting specifically — including the cinematography vocabulary and shot-consistency techniques relevant to AI filmmaking pipelines.

**If you want to systematically improve your own prompts:**
The Meta & Optimization cluster (67–80) — especially [`67_Meta_Prompting`](prompt_library_part2/67_Meta_Prompting.txt), [`70_Prompt_Optimization`](prompt_library_part2/70_Prompt_Optimization.txt), and [`78_Automatic_Prompt_Engineering`](<prompt_library_part2/78_Automatic_Prompt_Engineering_(APE).txt>) — covers using AI to design, test, and refine your own prompts rather than relying on manual guesswork.

## 📁 File Format

- **Format:** Plain `.txt` — readable anywhere, zero dependencies, fully portable
- **Structure:** Fixed 10-part format across all 80 files for predictable navigation
- **Naming convention:** `##_Technique_Name.txt` (zero-padded, sorts correctly on any system)
- **Length:** ~250–400 lines per file
- **Total library size:** 80 files across two folders — `prompt_library_part1/` (01–40) and `prompt_library_part2/` (41–80)

> **Note on links:** two files — `33_Retrieval-Augmented_Generation_(RAG)_Prompting.txt` and `78_Automatic_Prompt_Engineering_(APE).txt` — contain parentheses in their filenames. Their links above are wrapped in `<...>` per standard Markdown syntax, which is required whenever a linked path itself contains parentheses.
